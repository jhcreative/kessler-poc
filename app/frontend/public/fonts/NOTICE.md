# Fonts

Self-hosted, copied from Tailor's font library (`~/jhc/tailor/definitions/fonts`, Tailor v1.1.5), Latin subset only.

- **IBM Plex Sans** 400, 500, 600 (IBM): SIL Open Font License 1.1.
- **Roboto Condensed** 300, 500 (Google): SIL Open Font License 1.1 or Apache 2.0, per Google Fonts.

Both licences allow embedding in software. Tailor marks the library "verify before client use". Verify before this
moves past a demo.
