POC Application Design

Proof of Concept•Kessler Facility Services•November 16, 2026

Our single source of truth supports an application where any given job record can be trusted to always show the latest data and state of a request to every role to empower and speed decision-making at every point in the system.

1FIVE VIEWS

Each role sees its own work.

Coordinator, dispatch, tech, controller and an executive overview. The tech's phone shows only that tech's jobs; the overview shows them all.

2DRAFTS, THEN PEOPLE

Software drafts; people decide.

Agents draft each request from its source, labelled as a draft. Coordinators review drafts for accuracy, update and accept into the system.

3PRE-LOAD THE RULES

Contracts stop disputes early.

The system already knows the the contract specifics before a request is accepted. Adding relevant guardrails to request data enables pre-emptive decision making throughout that should reduce dispute resolution later.

4LIVE

Every change, in every view.

One view's change shows in every other open view within a second, with no reload. Views that drop a connection replay missed when back online.

5ON THE CLOCK

Every step of the way.

Timestamped events in centralized system facilitate future dataset analysis and identification of areas for improvement.

6BUILT SMALL

Owned, tested, typed.

About 4,600 hand-written lines, tested at every layer and audited by a fresh reviewer. Types generated from the backend keep the screens in step.
