What We Did

Proof of Concept•OneFamilyServices•November 16, 2026

We mapped how one request moves through OneFamilyServices, from the client's first message to payment. Then we found where each step can improve, and built a working proof of concept around one shared record.

1THE MAP

Nine steps, one request at a time.

Intake, coordination, estimation, dispatch, onsite, close, billing, invoicing and collections. Page 2 draws each step as the COO described it.

2WHERE IT LEAKS

People carry the system by hand.

Three people re-key 20,000 requests a quarter. Dispatch runs through one person on a personal phone, billing through another. Contract limits don't reach the tech, so $80,000 to $200,000 a year in disputed work is written off.

3WHERE IT CAN IMPROVE

Nine efficiencies that add up.

Each one removes a wait or a hand-off. Five can start on their own; four arrive with the shared record. Page 6 numbers them, ranks them and estimates what each saves, in hours and in Cost of Delay.

4WHAT WE BUILT

One record, five views, live.

Coordinator, dispatch, tech, controller and an executive overview, each updating the same job record in real time. It runs on synthetic data at ofs.apps.johnhiemstra.com.
